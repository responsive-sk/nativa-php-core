# 28. Retiring the extract-check

Measured 2026-11-18, on `fd84123` plus the theme import and `wip/pre-unify`.

## What the check measured

`bin/build/extract-kernel.sh --check` compared this tree with a checkout of
`evan70/nativa-minimal` and accepted a difference only when
`bin/build/kernel-divergence.txt` recorded it. That record was 249 lines: the
kernel became this repository's source of truth at the import on 2026-10-11,
and ten boots of deliberate work stood between the two slices.

The gate did not run in CI at all. The upstream repository is private, the
run's `GITHUB_TOKEN` is scoped to this one, and a cross-repository checkout
answers `404 (Not Found)`. The job said `NOT RUN` in those words.

Locally, on 2026-11-18, it was red: **7 unrecorded differences**. One of them
was `Frontend/packages/pnpm-workspace.yaml`, which gained an `auditConfig` here
after the import; the rest were the same kind of post-import work. A gate that
is red on the machine and skipped in CI was not measuring the tree.

## The decision

The comparison is retired, not repaired:

- the kernel's source of truth is this repository, and it has been since the
  import; `docs/repo-map.md` states the direction for every repository;
- the showcase remains a site that installs modules from this catalogue, so it
  is a consumer, not a second kernel;
- the final state is this record: 249 recorded divergences at the last green
  run, 7 unrecorded differences at retirement, and the work that produced them
  preserved on `wip/pre-unify` in the showcase repository.

Removed in the same commit: `bin/build/extract-kernel.sh`,
`bin/build/kernel-divergence.txt`, the `extract-check` target and its Makefile
variable, the CI job, the registry rows (a gate and a job), the two prune lines
and the export-verify entries. The production wrapper no longer calls the
guard.

## What still holds the direction

`bin/cms module:add` installs from the catalogue, `make modules-install` proves
the closure, `make dist-check` builds a clean clone, and the published tree is
generated by `bin/build/publish-core.sh` with a marker naming its source commit.
None of those needs the upstream checkout.
