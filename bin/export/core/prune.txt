# The nativa-core export: paths that stay in nativa-php-core.
#
# Format: <repo-relative path> [# reason]
#
# A path names a file or a directory, and a directory prunes its whole subtree.
# The exporter FAILS when an entry matches nothing, so a path that moved is a
# red run instead of a rule that quietly stopped pruning.
#
# Every line here is a decision. A file added to this tree and never classified
# still ships, which is why the exported suite runs as part of the check.

# The boot log, the approval ledgers, the article archive and the writing rules.
# They record how THIS tree was built, and the numbers in them belong to it.
docs

# The catalogue: the export ships the Nativa theme, Settings (the theme vote),
# ContentLocale (the locale-to-URL-prefix rule every theme asks for), RestPanel
# (the REST panel under /mark/rest) and the admin stack RestPanel's closure
# needs: Cardboard, Users, Auth, Locales, Navigation, Notifications, Outbox,
# PageCache, Pagination, Security, Uploads and Validation. Blog ships too: it
# owns /blog and the articles admin at /mark/articles, with the closure it
# needs (Audit, Markdown, Media, Queue). Cardboard and Users are what make
# /mark a gated admin area at all; RestPanel and Blog cannot install without
# them. Docs is a module with no guides in this export, so it is pruned with
# the other optional modules.
#
# Measured (`bin/lab/core-surfaces.sh` and the file counts of the slices): the
# theme renders with Settings + ContentLocale; the admin surface (RestPanel
# plus the closure of Cardboard and Users) costs +311 files; the Blog surface
# (Blog plus Audit, Markdown, Media and Queue) costs +156; Pages costs +18
# and is not a dependency.
