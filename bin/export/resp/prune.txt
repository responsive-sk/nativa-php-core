# The nativa-resp client port: paths that stay in nativa-php-core.
#
# Format: <repo-relative path> [# reason]
#
# A path names a file or a directory, and a directory prunes its whole subtree.
# The exporter FAILS when an entry matches nothing, so a path that moved is a
# red run instead of a rule that quietly stopped pruning.
#
# Module directories are NOT listed here. profile.json owns the allow-list, and
# the exporter prunes every catalogue entry it does not name and fails on a
# named module that is absent.
